# Как подключить контент от заказчицы

Всё, что присылает Анастасия — товары, фотографии, отели, цены, промокоды,
контакты — лежит в одной папке `workspace/content`. В коде приложения этого
нет: оно читает подготовленные файлы при запуске.

Поэтому новый каталог подключается без правок в Dart: поменял файлы,
запустил скрипт, пересобрал.

## Папка content

```
workspace/content/
  settings.json   бренд, суммы доставки, оплата, склад, контакты, промокоды, баннеры
  hotels.json     отели: название, адрес, координаты
  catalog.json    категории и товары
  photos/         фотографии товаров, имя файла = SKU (p01.jpg, p02.jpg…)
```

## Порядок действий

1. **Фотографии.** Положить в `content/photos`. Имя файла должно совпадать с
   полем `sku` товара: товар с `"sku": "p07"` берёт `p07.jpg`. Формат —
   jpg или png, квадрат, желательно от 600×600.

2. **Каталог.** Открыть `content/catalog.json`. Поля товара:

   | поле | что это | обязательно |
   |---|---|---|
   | `id` | номер товара, уникальный | да |
   | `sku` | код, по нему ищется фотография | да |
   | `categoryId` | номер категории из этого же файла | да |
   | `name` | название на витрине | да |
   | `description` | 2–3 предложения в карточке товара | да |
   | `price` | цена в рублях | да |
   | `oldPrice` | старая цена, рисует бейдж скидки | нет |
   | `unit` | «шт», «250 г», «1 л» | да |
   | `isAvailable` | `false` — товар показывается недоступным | нет |

   Категории: `id`, `name` и `icon`. Иконки: `gift`, `spa`, `basket`,
   `cafe`, `cake`, `beach`, `drink`, `health`, `baby`, `home`.

3. **Отели.** `content/hotels.json`: название, адрес, координаты, `active`.
   Координаты нужны карте курьера — без них маркер отеля встанет в море.
   Выключить отель из списка можно, не удаляя: `"active": false`.

4. **Настройки.** `content/settings.json`: минимальная сумма заказа, цена
   доставки, порог бесплатной доставки, промокоды, тексты баннеров на
   главной, контакты поддержки, ссылка на политику конфиденциальности,
   координаты склада, откуда выезжает курьер.

   Промокод: `percent` — процент, `fixed` — рубли. `"active": false` —
   код перестаёт работать и показывает ошибку на чекауте.

5. **Применить:**

   ```
   python workspace/tools/apply_content.py
   ```

   Скрипт проверит каталог, разложит фотографии и подготовит файлы для
   приложения. Проверить присланное, ничего не меняя:

   ```
   python workspace/tools/apply_content.py --check
   ```

6. **Пересобрать** приложение — `flutter build` или `flutter run`.

## Что скрипт ловит сам

- повторяющиеся номера товаров;
- товар без названия, описания или цены;
- ссылку на несуществующую категорию;
- старую цену меньше новой (бейдж скидки показал бы наценку);
- отсутствующие фотографии — подставит временные и перечислит, каких нет.

Пока чего-то не хватает, скрипт печатает список — его удобно пересылать
заказчице как «вот чего ждём».

## Чего сейчас не хватает

На момент последнего запуска: нет ни одной настоящей фотографии товара
(стоят временные), не заполнены телефон поддержки, ссылка на политику
конфиденциальности, страница поддержки и логотип. Последние три —
обязательное требование App Store и Google Play.

## Что осталось за пределами настроек

Тексты интерфейса (кнопки, подписи, ответы чат-бота) живут в файлах
локализации `client_app/lib/l10n/*.arb` на трёх языках. Описания товаров
пока только на русском: если нужны английский и турецкий варианты
карточек, в `catalog.json` добавляются поля вида `nameEn`, `nameTr` — это
небольшая доработка, но её надо заказать отдельно.
