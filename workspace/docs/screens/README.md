# Скриншоты для показа

Кладутся сюда сессиями, которые делают экраны. Снимать в Chrome на узком
окне (примерно 390×844 — размер айфона), демо-режим включён:

```
cd workspace\client_app
flutter run -d chrome --dart-define=DEMO=true
```

## Порядок для отправки

Заказчице удобнее смотреть по ходу сценария, а не по алфавиту:

каталог → карточка товара → корзина → оформление → промокод → заказ
оформлен → отслеживание на карте → список заказов → фото доставки → чат →
профиль на турецком → заказы курьера → фото коробки

## На что смотреть перед отправкой

- фото товаров видны, а не серые прямоугольники
- нет полос переполнения по краям (жёлто-чёрная штриховка)
- цены с пробелом и рублём: `1 250 ₽`
- нигде не осталось английских системных надписей вроде `DEBUG`
